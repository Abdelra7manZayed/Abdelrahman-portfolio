# Abdelrahman Gamal Zayed — AI/ML Portfolio

A production-oriented personal portfolio built with **Next.js, TypeScript and Framer Motion**.

## Highlights
- Dark / light theme with persistent preference
- Motion-first but performance-conscious UI
- Responsive desktop / tablet / mobile layout
- Personal portrait integrated in the hero
- ML, DL, Computer Vision, NLP and GenAI project filters
- Project case-study modal with supplied demo recordings
- Dedicated solar forecasting research presentation
- NLP project cover artwork
- Certifications linked to the supplied PDF files
- Experience / training timeline
- Leadership & community section covering Microsoft Students Club, IEEE and EYE
- CV download
- GitHub / LinkedIn / contact links
- No external API dependency for GitHub data
- `prefers-reduced-motion` support

## Run locally
```bash
npm install
npm run dev
```
Open `http://localhost:3000`.

## Production build
```bash
npm run build
npm run start
```

## Deployment
Designed for Vercel. The site is static-content driven and does not require secrets or a backend.

## Content
Project and profile content is centralized in `data/content.ts`. Replace assets in `public/assets/` when updating the portfolio.
