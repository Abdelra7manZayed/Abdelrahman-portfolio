# Abdelrahman Gamal — Creative 3D Portfolio

Next.js portfolio with an editorial, motion-led design inspired by high-end creative personal-brand sites and the Lando Norris digital experience, while keeping an original AI-engineering identity.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run build
npm start
```

## Deploy to Vercel

Push this folder to GitHub and import the repository into Vercel. Vercel detects Next.js automatically.

## Highlights

- Dark / light theme
- Performance-conscious motion
- CSS 3D hero composition
- Editorial marquee and scroll reveals
- Interactive project cards and case-study modal
- Responsive `next/image` assets
- Reduced-motion support
- Fake News NLP live demo: https://fake-news--veridica.streamlit.app/
- Easy content updates through `data/content.ts`

The Fake News project is prepared for a future demo video; the live Streamlit demo is already linked.
